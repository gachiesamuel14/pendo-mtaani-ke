# Pendo Mtaani

Location-based dating app for Kenya. Connect with people nearby in Nairobi, Mombasa, Kisumu, Kiambu and more.

## Features

- User profiles with photos, bio, interests, county
- GPS / location-based discovery
- Swipe to like/pass
- Matches and chat (demo)
- Filters by county, distance, age
- Safety tips
- Ready for M-Pesa premium features

## Tech Stack

- Frontend: React + Vite + Tailwind CSS + React Router
- Deployed on Netlify
- Backend (to be added): Supabase / Firebase / Netlify Functions + PostgreSQL for real auth, storage, real-time chat

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

Connected to Netlify. Push to main triggers deploy.
